# Law Portal - Legal Database System

A comprehensive law listing portal built with Django and PostgreSQL.

## Features
- 📚 Category-wise law organization
- 🔍 Search functionality
- 💼 Admin panel for content management
- 📱 Responsive design

## Live Demo
[View Live Site](https://your-app-name.railway.app)

## Technologies Used
- Django 4.2
- PostgreSQL
- Bootstrap 5
- Python 3.10

## Local Setup
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Setup database
4. Run: `python manage.py runserver`
